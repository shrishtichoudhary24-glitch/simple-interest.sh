# github-final-project

## Simple Interest Calculator

This project contains a Bash script, `simple-interest.sh`, that calculates simple interest from user input.

### Purpose
To practice the GitHub workflow (repository, license, code of conduct, contributing guide) while building a small useful tool.

### Formula
Simple Interest = (Principal x Rate x Time) / 100

- **Principal**: the initial amount of money
- **Rate**: the annual rate of interest (%)
- **Time**: the time period in years

### How to Use
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
The script asks for the principal, rate of interest, and time period, then prints the result.

### Example
```
Enter principal amount: 1000
Enter rate of interest (%): 5
Enter time period (years): 2
Simple Interest = 100.00
```
